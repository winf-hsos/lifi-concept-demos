the noisy sensor

the same readings, decided three ways: alone, averaged over five, averaged over ten.

sensor noise last symbol: — space · send   b · send 25   r · reset   1 / 2 / 3 · noise
led off threshold led on reads as off reads as on

all three lanes read the same sensor at the same moment. they differ only in how many of those readings they average before deciding. a red dot is a wrong decision: that reading landed on the far side of the threshold. the plot keeps the last 40 symbols, the numbers count every one.

simulated readings — your own setup supplies the real numbers.

one reading is a guess. a series is evidence, and it costs you time.
